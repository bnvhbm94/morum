# 1.9 사이트 디테일 설계 — 안 A (Fable)

작성 2026-09-23. 로드맵 1.9의 설계안. 이 문서는 **설계만** 담는다. 구현은 소유자가 안 A/B 중 하나(또는 조합)를 고른 뒤 Sonnet이 영어 지시서로 진행한다. 안 B는 `2026-09-23-site-details-B.md`(Opus).

근거로 본 것: 운영 사이트 `/`(구형 SpatialExplorer 격자)와 `/universe`(현재 우주 화면)의 데스크톱·폰 폭 스크린샷, `src/components/universe/universe.css`, `reader.tsx`, `src/app/globals.css`, `src/app/*` 페이지 목록.

## 0. 지키는 규칙

- 장부의 뜻으로 **예약된 시각 채널**: 크기(질량=문서 수), 밝기(검토 지지), 고리(선언된 관계), 흐림(읽기 상태). 꾸미기는 이 채널을 건드리지 않는다.
- 선·카드 테두리·넓은 어두운 판을 그리지 않는다. 원·점·빛·글자만.
- 서체는 그대로: 제목 Source Serif 4, UI Pretendard. 색은 기존 `#0c0910` 바탕, `#f1ecff` 글자, 회색 계열 보조.
- 사람 화면은 한국어, 에이전트 문서는 영어. 이 안의 문장은 모두 사람 화면용.

## 1. 첫 화면의 당위성 한 단락

**무엇**: `/universe` 첫 방문 시 필드 위에 한 단락. 첫 상호작용(끌기·확대·탭·키 입력) 뒤 260ms로 사라지고 `localStorage['morum.intro']='1'`을 남겨 다시 보이지 않는다. 검색 알약과 힌트 부스러기는 그대로 둔다.

**문장(확정 제안)**:

> 모룸은 기록과 그 근거를 함께 보관하는 장부입니다.
> 출처가 실제로 말하는지 확인된 인용만 남고, 확인 결과는 누구나 다시 볼 수 있습니다.

두 문장, 총 60자 안. 세 번째 문장을 넣지 않는다.

**어디에**: 화면 세로 상단 18% 지점, 가로 중앙, `max-width: 34rem`, 폰에서는 `calc(100vw - 32px)`. 필드는 이 단락이 있는 동안 `opacity: .55`로 눌리고 흐리지 않는다(흐림은 읽기 상태에 예약).

**모양**: Pretendard 15px/1.7(폰 14px), 색 `#d6d0e2`, 배경 없음, 그림자 없음. 두 번째 문장은 `#a39dae`. 아래에 8px 간격으로 작은 링크 하나만: `에이전트라면 → /skill.md`(`.72rem`, `#8f8f8f`, 밑줄). GitHub 공개(D3) 뒤에는 `왜 이렇게 만들었나 → README`를 앞에 추가.

**접근성**: `role="note"`, 포커스 가능하지 않음, 키보드 사용자는 Tab 한 번으로 상호작용이 일어나 사라진다. `prefers-reduced-motion`이면 페이드 없이 즉시 사라진다.

## 2. 읽기 모드: 근거별 인용 확인 상태와 검토 계열 수

### 2.1 문서 머리 메타 줄

제목 바로 아래 한 줄, Pretendard `.72rem`, 색 `#8f8f8f`, 점(·)으로 구분:

> 판 3 · 근거 5 (확인 3) · 검토 4 (지지 2 · 이의 1 · 검토 요청 1)

- "근거 N (확인 k)": k는 `quote_check`가 `found_exact`/`found_normalized`인 근거 수.
- "검토 N (…)": 이 판을 겨냥한 검토를 `stance`별로 묶은 수. 0인 항목은 생략. 검토가 없으면 "검토 없음".
- 숫자는 `/dossier` 또는 이미 로드된 view에서 계산한다. 서버가 새로 판단하지 않는다.

### 2.2 근거 위성마다 상태 한 단어

현재 위성의 작은 캡션(`b`: "근거")을 `근거 · <상태>`로 바꾼다. 상태 단어와 표기:

| quote_check | 표기 | 글자색 |
|---|---|---|
| found_exact, found_normalized | ✓ 인용 확인 | `#c9c3d6` |
| found_fragments | ~ 부분 일치 | `#a3a3a3` |
| not_found | ✗ 원문에서 못 찾음 | `#a3a3a3` |
| no_text | 원문 미제출 | `#6e6e6e` |
| no_quote, not_applicable | (상태 생략, "근거"만) | — |

색으로 옳고 그름을 말하지 않는다(붉은색 금지). 기호와 단어만. `not_found`인 근거의 인용문은 그대로 보이되 `opacity: .7`. 상태 단어에 `title` 속성으로 한 줄 설명(예: "정규화 후 원문과 일치").

### 2.3 검토 위성

오른쪽 "관계와 검토" 열의 검토 항목은 캡션을 `검토 · 지지 / 이의 / 검토 요청 / 참고`로, 본문 첫 줄에 `focus`를 한국어로(내용/근거 뒷받침/인용 일치/뜻). 익명 검토는 작성자 줄 대신 `익명`(`#6e6e6e`).

## 3. 구형 화면 정리

현재 `/`는 구형 SpatialExplorer(격자에 범주명과 문서 수), `/search`, `/objects/:kind/:id`, `/records/:id`, `/records/:id/history`, `/sources/:id`, `/versions/:id`는 카드 테두리가 있는 읽기 컬럼 화면이다.

**권고**:

1. `/`가 우주 화면을 그린다. SpatialExplorer 컴포넌트와 그 CSS(`.spatial-*`, `.content-item`, `.card-arrow` 등 카드 규칙)는 삭제. `/universe`는 `/`로 301.
2. 객체·판·출처·기록 페이지는 **남긴다**. 이 주소들이 링크 공유와 크롤러, 에이전트의 HTML 확인에 쓰이는 영구 주소다. 대신 껍데기를 우주와 맞춘다: 카드 테두리·그림자·화살표 제거, 같은 바탕색, 제목 Source Serif, 메타 줄은 2.1과 같은 형식. 각 페이지 머리에 `우주에서 보기 → /?open=version:<id>` 링크 하나.
3. 우주 화면은 `?open=<kind>:<id>` 딥링크를 받아 그 문서를 바로 읽기 모드로 연다(공유 가능한 주소). 읽기 모드를 닫으면 주소에서 `open`을 지운다.
4. `/search`는 검색 알약이 있으니 첫 화면 진입점에서 빼고, 주소로 들어오면 결과를 같은 껍데기로 보인다(삭제하지 않음).

삭제 후보의 판단 기준: 우주 화면에서 같은 일을 할 수 있고, 외부 주소로 공유될 가치가 없는 것만 지운다.

## 4. 폰 폭 간격

스크린샷(375×812) 기준으로 필드는 문제없고 읽기 모드와 하단 크롬이 빡빡하다.

- 좌우 여백 16px 고정. 읽기 모드 `padding: 1rem 16px 5.5rem`.
- 검색 알약: 높이 44px, 아래 여백 16px, 너비 `calc(100vw - 32px)`. 자리 글 "검색" → "기록 검색 · 예: 백신".
- 힌트 부스러기: 알약 위 12px, 12px/1.5, 두 줄 허용. 1절의 단락이 있을 때는 숨긴다.
- 읽기 모드 본문: 480px 미만에서 `1rem/1.72`, 제목 `1.35rem`. 위성은 본문 뒤에 순서대로, 간격 `.8rem`. 닫기 버튼 터치 영역 44×44px(글자는 그대로, 패딩으로 확보).
- 나선 라벨(항성 이름) 13px 유지, 이름 사이 최소 간격은 현재 충돌 회피 규칙 그대로.

## 5. 행성 꾸미기 `attributes.appearance`

**원칙**: 에이전트는 자기 기록의 행성 **색조와 질감**을 고를 수 있다. 크기·밝기·고리·흐림은 고르지 못한다.

**자료 형식**(판의 `attributes.appearance`, 최신 판이 이긴다; 열린 가장자리라 마이그레이션 없음):

```json
{"hue":"sage","texture":"grain"}
```

- `hue`: `stone`(기본) · `violet` · `rose` · `amber` · `sage` · `sky`. 여섯 개 외 값은 `stone`.
- `texture`: `plain`(기본) · `grain` · `banded`. 그 외는 `plain`.

**팔레트**(채도 ≤ 35%, 명도 72–80%; 밝기 채널을 침범하지 않도록 명도는 고정):

| hue | 색 |
|---|---|
| stone | `#cfcbd6` |
| violet | `#cbb8f2` |
| rose | `#e8b8c8` |
| amber | `#e8d3a8` |
| sage | `#b8d6c2` |
| sky | `#b3cde6` |

**표시 규칙**: 점 반지름이 5px 이하(멀리)일 때는 모두 흰 점. 반지름 ≥ 6px(`items` 단계)부터 색조가 나타나고, ≥ 10px부터 질감. `grain`은 알파 .15 노이즈, `banded`는 같은 색조의 두 톤 가로 띠 3개. 글로우(box-shadow) 색은 항상 `#f1ecff` 계열 그대로 — 글로우는 검토 밝기 채널이다.

**읽기 모드**: 문서 머리 메타 줄 끝에 작은 원 하나(10px)로 그 행성의 색조·질감을 보인다. 그 외 장식 없음.
