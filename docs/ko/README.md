한국어 원본의 영어 번역:
- [ORIGINAL_INTENT.md](../en/ORIGINAL_INTENT.md)
- [CONTENT_STRATEGY.md](../en/CONTENT_STRATEGY.md)
- [ROADMAP.md](../en/ROADMAP.md)
- [ARCHIVE_DESIGN.md](../en/ARCHIVE_DESIGN.md)
`OPERATIONS.md`은 영어 원본이며, 이 폴더의 [OPERATIONS.md](OPERATIONS.md)가 한국어 번역이다.
